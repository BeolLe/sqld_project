# ADsP 개념학습 반영

`/adsp/learn`과 `/adsp/learn/adsp-1-1`~`adsp-1-8`의 개념학습 본문을 위한 코드다. 기존 `LearnIndexPage`, `LearnUnitPage`, `BlockRenderer`, `LearnBlank`와 공통 로그인을 사용한다. 최신 main의 ADsP 29항목 목차 중 본문이 있는 8항목을 갱신하며, 나머지 21항목의 준비 중 상태를 유지한다. SQLD 30개 단원과 `/sqld/learn` 경로, 기존 경로의 리다이렉트도 유지한다. 이 검증은 배포 확인이 아니다.

## 본문과 채점

현재 본문은 **로컬 TypeScript**다. `REMOTE_LESSON_ENABLED = false`를 유지한다. 2026-11-01 개편본은 **8단원·54개 블록(개념 46개 + 단원별 핵심 정리 8개)·65빈칸**이며, 종전 24개 사례의 학습 포인트는 해당 개념의 설명·표·주의 사항으로 통합했다. 별도의 공통 `사례로 확인하기`나 번호형 문제/해설은 없다. 대신 **각 단원 마지막에 핵심 정리**를 두며, 기존 개념 3~8개를 목록으로 정리하고 빈칸은 추가하지 않는다. 단원별 블록 수는 6·6·9·6·5·10·6·6다. 8개 단원 ID와 기존 51개 빈칸 ID는 그대로이며 새 빈칸 14개를 추가했다. 기존 정오답 기록은 유지되지만 분모가 늘어 완료율은 달라질 수 있다.

ADsP 카탈로그의 용어 빈칸에만 `matchMode: 'term'`을 지정한다. 앞뒤 공백·대소문자와 용어 내부 공백을 정규화하되, 정답과 명시된 허용 답안만 인정한다. `군집분석`과 `군집 분석`도 허용한다. 부분 일치나 의미 추측은 하지 않는다. SQLD의 공백 경계 채점은 바꾸지 않는다. 새 힌트 UI는 추가하지 않았다.

빈칸 결과는 시험별 브라우저 저장소에 기록한다. 공통 계정·포인트와 기존 서버 테이블은 변경하지 않았다. 테스트용 가짜 인증·무전송 어댑터는 셀프체크 안에서만 사용한다.

## API와 DB 경계

API 헬퍼와 원격 레슨 훅은 `exam_type=sqld|adsp`를 전달하도록 준비되어 있다. 현행 API는 `education.curricula.exam_type`으로 소속을 판정하며 `lesson_versions.body_markdown`을 반환한다. **현재 본문과 빈칸을 API에서 읽는다는 뜻은 아니다.**

이번 개편은 DB에 접속하거나 적재 SQL을 실행하지 않았다. 별도 DB 적재 전달물이 있더라도 이번 TypeScript 개편과 자동 동기화되지 않는다. 기존 SQL 파일이 새 본문과 일치한다고 가정하지 말고 실제 실행 전에 검토해야 한다.

현재 DB API에는 LearnBlock/Blank JSON 필드가 없다. 정답을 본문에 넣은 Markdown만으로는 콜아웃 종류·빈칸 ID·허용 답안·채점 정책을 복원할 수 없다. API 전환에는 실제 DDL 확인 후 버전별 구조화 콘텐츠와 이를 반환하는 API 확장이 필요하다. 이 작업에서 임의의 컬럼·DDL은 도입하지 않았다.

## 검증과 한계

`npm run check:adsp-learn`은 8개 단원/기존 51개 빈칸 ID 보존과 최종 65개 빈칸, 토큰 대응, 표 구조, 종전 24사례 개념의 보존, 노트/퀴즈 SSR의 강조·코드·빈칸 마크업 누출 없음, 용어 답안, 미로그인·잘못된 시험 ID, SQLD 기본 경로, 진도 분리, API exam_type 및 404 처리를 검사한다. API 요청은 모킹하며 DB에 연결하지 않는다. `check:learn-blank-grading`은 SQLD 기존 채점과 6,870회 비교한다.

최종 실행 결과와 내용 검토는 `ADSP_CONTENT_REVIEW.md`를 참고한다. 브라우저 클릭·모바일 화면·실제 로그인·실제 API/DB·배포 자산 검증은 수행하지 않았다. SSR 성공을 브라우저 E2E 성공으로 해석하지 않는다.

코드 롤백은 적용한 코드 변경을 되돌리는 방식이다. SQLD 데이터 삭제·공통 포인트 재산정은 포함하지 않는다. 코드 롤백만으로 별도로 적재한 DB 데이터를 삭제하지 않는다.

## 시험 지식 보강 범위와 평가 해석

2026-11-01 추가 보강은 기존 8개 세부항목 안에서 빠진 이름·정의·대비·역사적 사례를 채우는 작업이다. 시험 원문·보기·정답 해설을 본문에 복사하거나 보기 문구를 외우게 하지 않는다. 확인 가능한 1차 출처와 적용 시점은 `ADSP_KNOWLEDGE_SOURCES.md`에 기록한다.

확인된 학습 공백은 출처를 바탕으로 보강하고, 출처나 해석의 모호성은 설명의 적용 범위를 구분한다. 본문의 커버리지 검사는 **학습·회귀 커버리지**를 확인하는 것이며 처음 보는 시험의 정확도나 일반화 성능을 보장하지 않는다.

데이터베이스의 중복이 전혀 없어야 한다거나, 핀테크의 한 분야가 언제나 가장 중요하다거나, 풍향·수요예측이라는 이름만으로 데이터 형식을 고정하는 규칙은 추가하지 않는다. BI/BA와 분석 기법의 범주 중첩, 클라우드 비용의 조건, 비식별 처리와 법적 익명정보의 구별도 유지한다.
