# 이용약관·개인정보처리방침 개정 (시행 2026-11-09)

SQLD·ADsP 통합(PR #44)에 맞춰 서비스 범위를 고치고, 처리방침의 누락 항목을 보강한다.
공지 시작일에 맞춰 시행일을 정한다. 이용약관 제3조에 따라 시행 7일 전부터 공지해야 하므로,
2026-11-02까지 공지하지 못하면 `frontend/src/constants/legal.ts`의 시행일을 함께 미룬다.

## 변경 대비표

### 이용약관
| 조항 | 변경 전 | 변경 후 |
|---|---|---|
| 제1조 | SQLD 자격증 대비 모의고사 및 SQL 실습 서비스 | SQLD·ADsP 등 자격증 대비 모의고사, 개념 학습, 무한풀이 및 SQL 실습 서비스 |
| 제2조 제1항 | SQLD 모의고사, SQL 실습, 학습 대시보드 등 | SQLD·ADsP 등 자격증 대비 모의고사, 개념 학습, 무한풀이, SQL 실습, 학습 대시보드 등 |
| 제5조 제3항 | 없음 | 자격증 종류별 기능·콘텐츠 차이와 준비 중 기능의 이용 제한 안내 신설 |

### 개인정보처리방침
| 항목 | 변경 내용 |
|---|---|
| 1. 수집 항목 | 가입 목적(선택), 개념 학습 진도, 시험 종류 구분 정보, 피드백·오류 제보 내용 추가 |
| 2. 수집·이용 목적 | 시험 종류별 학습 기록, 무한풀이·개념 학습 결과 명시 |
| 4. 위탁·국외 이전 | 국외 전송 시점과 방법 안내 추가 |
| 8. 자동 수집 장치 | 쿠키·브라우저 저장소 사용과 거부 방법 신설 |
| 9~11 | 번호 조정 |
| 12. 변경 | 시행 7일 전 공지 신설 |

## 공지문 초안

> **서비스 이용약관 및 개인정보처리방침 개정 안내**
>
> SolSQLD에 ADsP 학습 서비스가 추가되어 약관과 개인정보처리방침을 개정합니다.
> - 시행일: 2026년 11월 9일
> - 주요 내용: 서비스 범위에 ADsP 등 자격증 학습 추가, 수집 항목과 쿠키 등 자동 수집 장치 안내 보강
> - 개정 내용에 동의하지 않으시면 시행일 전까지 회원 탈퇴를 요청하실 수 있습니다.

## 재동의

기존 회원 재동의는 받지 않는다. ADsP 추가는 수집 항목과 목적이 기존 범위와 같다는 판단이며,
법률 검토 결과에 따라 달라질 수 있다.

## 배포 전 작업

- [ ] `auth.consent_versions`에 2026-11-09 버전 등록 (terms, privacy_policy). 2026-07-19 버전 등록 여부도 함께 확인
- [ ] 법률 검토

## 이번 범위에서 제외

- Amplitude 관련 문구: 사용 중단 예정. 중단 시 처리방침 위탁 목록에서 제거하고 초기화 코드를 정리한다.
- 국외 수탁자의 연락처와 보유 기간 상세: 확인 후 추가한다.
- 회원가입 가입 목적의 ADsP 선택지: 약관 외 화면 변경이라 별도로 진행한다.
