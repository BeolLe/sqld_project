# ADsP 본문 개편 검토 — 2026-11-01

## 결과

8개 단원의 본문 전체를 읽고 검토했다. **54개 블록(개념 46개 + 단원별 핵심 정리 8개), 65개 빈칸**이며 단원 ID 8개와 기존 빈칸 ID 51개를 유지하고 새 빈칸 14개를 추가했다. 개념마다 정의를 먼저 설명하고 가까이에 예시·비교표를 배치했다. 개념별 암기·함정은 필요한 곳에 둔다. 이와 별도로 **모든 단원의 마지막에는 핵심 정리 블록**을 두어 핵심 구분 3~8개를 목록으로 복습한다. 핵심 정리에는 새 빈칸이나 새 개념을 추가하지 않는다. 공통 마무리 사례/Q&A와 반복적인 모드 사용 안내는 제거했다. 새로운 힌트 UI나 SQLD 본문 변경은 없다.

검토 기준은 저장소의 실제 SQLD 30단원·163블록이다. SQLD는 단원마다 블록 수와 노드 구성이 다르므로 ‘항상 다섯 블록’ 같은 고정 틀을 만들지 않았다. ADsP 6단원의 밀집된 분석 기법 표는 연관규칙·분류/군집·유전알고리즘·회귀·연결망·기계학습/감정분석으로 나누어, 후보 해·계수·노드·링크를 바로 설명한다. 1~4단원의 필드·스키마·키·태그와 주요 약어도 첫 등장 가까이 설명한다.

## 정확성 및 렌더링 검토

- OLTP는 등록·변경만이 아니라 현재 주문 상태 같은 일상 거래 조회도 포함하도록 수정했다.
- DW 비휘발성은 일상 거래에 따라 과거 기록을 덮어쓰지 않는다는 의미로 설명하고, 오류 정정·보존 정책의 예외를 구별했다.
- 가명정보는 여전히 개인정보다. 익명정보 설명에는 **다른 정보를 사용하여도** 개인을 알아볼 수 없다는 조건을 포함했다. 담당 작성자가 [국가법령정보센터 개인정보 보호법 제58조의2](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1034292489)를 2026-11-01 확인했다. 학습상 통제 방향을 일괄적인 법적 처리 허가로 해석하지 않도록 구분했다.
- 대출 사례는 높은 위험 점수로 일관되게 표현한다. 예측과 실제 위반의 책임을 혼동하지 않는다.
- 군집/군집화/군집분석/군집 분석의 명시된 답안을 인정한다. 분류 등 다른 개념은 거부한다. 용어 공백 정규화는 ADsP 카탈로그에만 적용한다.
- 통합 중 발견한 결함: `**{{빈칸}}**` 중첩은 기존 InlineText가 재귀적으로 처리하지 않아 입력창이 사라졌다. 작성자가 중첩 강조를 제거했고, **최종 모든 블록의 노트/퀴즈 SSR을 다시 통과**했다. 공통 렌더러는 변경하지 않았다.

## 추가 보강의 검토 원칙

- 학습 공백은 확인 가능한 출처로 보강하고, 출처나 해석이 모호한 부분은 단정하지 않는다. 커버리지 검사는 학습 범위의 회귀 검사이며 미공개 시험 정확도를 보장하지 않는다.
- 정확한 의미를 설명하는 새 문장과 표를 사용한다. 원문 문제·보기·정답키의 특이한 구분을 복사하지 않는다.
- 역사적 기업 사례는 연도와 출처를 명시하고 현재 서비스의 운영 상태로 확대하지 않는다. 확인 출처와 보강 위치는 `ADSP_KNOWLEDGE_SOURCES.md`를 참조한다.
- 종전 51개 빈칸 ID는 부분집합으로 보존한다. 신규 빈칸은 고유 ID로 추가하며, 기존 진도의 정오답은 유지되지만 총 빈칸 수 증가에 따라 완료율은 달라질 수 있다.
- 이전 검사가 놓친 단독 강조 구분자를 막도록 문자열마다 강조/코드 구분자의 짝을 검사한다. 노트·퀴즈의 실제 SSR 출력에도 리터럴 `**`, 백틱, 미해결 빈칸 토큰이 없어야 한다. 입력 개수만으로 렌더링 성공을 판단하지 않는다.
- 모든 기존·신규 허용 답안과 공백/대소문자 변형을 확인한다. `u2_b6`의 ‘동시 공용’, `u6_b5`의 ‘유형분석’ 회귀 사례와 각각 다른 개념의 오답 거부를 별도로 검사한다.
